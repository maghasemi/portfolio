PhD project A · Sporadic Parkinson's disease

Where does carbon go when a mitochondrial enzyme slows down?

Evidence of: mechanistic modeling · robustness analysis · single-cell transcriptomics

The question

Neural precursor cells from patients with sporadic Parkinson's disease show reduced activity of a key TCA-cycle enzyme (OGDHC). Respiration measurements alone can't tell where the carbon goes instead.

What I built

  • Donor-level pseudo-bulk differential expression on public single-cell RNA-seq: 7 patient and 5 control donors, 30,557 cells.
  • An ODE model of the acetyl-CoA branch point in MATLAB: 11 metabolites, 14 fluxes, thermodynamic constraints from eQuilibrator.
  • Stress tests: 1,000 Monte Carlo parameter sets, 500 expression-noise runs, sensitivity analysis and 8 in silico intervention scenarios.

R package · open source · metMatchAudit

Same name. Same compound?

Tools such as MetLinkR link metabolomics datasets by giving every row a standardized name. metMatchAudit runs after that step: for every pair of rows that share a name, it looks at the structural evidence and reports how the two actually relate, with the rule that decided it.

Evaluation

Tested in one development review and four blind tests. Each test fixed its criteria and labels before the tool ran on its data. The chart shows the blind tests as they came out, including the criteria that were not met.

How I work

Five habits behind every analysis

01

Define the system

What goes in, what comes out, what the model or analysis may claim.

02

Fix the criteria first

Thresholds, gene sets and expected directions are set before looking at results.

03

Build it as code

Scripts and pinned environments that others can re-run.

04

Stress-test

Sensitivity analysis, leave-out tests, independent data.

05

Say what it can't show

Limits are stated next to the result.
